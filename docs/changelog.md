# NexLink 更新日志 (Changelog)

## [0.1.0] - 2026-11-02

### 🌟 核心特性
* **全格式智能导入中心**：支持粘贴单节点 URI (VMess / VLESS / SS / Trojan / Hysteria2 / TUIC / WireGuard)、Base64 订阅包、Clash YAML 与 Sing-box JSON，本地无损提取转换。
* **现代毛玻璃 UI**：支持暗色与浅色双主题无缝切换，提供流量仪表盘、节点列表与延迟测速工作台。
* **原生系统网络接管**：支持 Windows WinINet 系统代理与 TUN 虚拟网卡模式（混合堆栈）。
* **平滑热更新与系统托盘**：更新订阅零断网，支持关闭窗口最小化至托盘与开机自启。

### 🛡️ 安全与稳定性强化
* **时区与退避修复**：修复订阅定时拉取时区解析 Bug 与失败订阅死循环重试缺陷。
* **确定性节点 ID**：基于协议参数生成固定哈希 ID，保证订阅刷新后选定节点永久保留。
* **死代理防范**：注册表代理读写持久化备份，同步毫秒级恢复网络直连，启动自动清理残留死代理。
* **坏节点校验与防崩**：严格校验 1-65535 端口与合法主机，配置生成器自动过滤畸形节点。
* **数据目录合规**：运行时全部迁移至 `%APPDATA%\NexLink\runtime`，支持打包安装无权限报错。
* **流式安全拉取**：订阅下载全局超时覆盖完整数据流，严格限制 10MB 体积上限。
* **DNS 与通信安全**：未开启局域网共享时严格监听 `127.0.0.1`，IPC 通信与外部链接协议白名单校验。
* **存储容灾与快照**：JSON 存储引入损坏容灾备份（`.corrupted` 与 `.bak`），防止断电数据丢失。
